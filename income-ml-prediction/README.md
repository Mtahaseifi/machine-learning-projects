# About the Project

This project utilizes a Decision Tree machine learning model to predict an individual’s income level based on key demographic and professional features, including:

    Age
    Education level
    Marital status
    Weekly working hours
    Occupation class

The model was trained, evaluated, and achieved high accuracy in predicting income categories.

# Libraries Used

    Pandas: Used for data manipulation, cleaning, and preprocessing.
    Scikit-learn: Used for implementing the Decision Tree algorithm, model training, and performance evaluation.
    Matplotlib: Used for data visualization, plotting the confusion matrix, and interpreting the decision-making process of the model.

# How to Run

   1.Clone this repository:

   2.Install the required dependencies:

                                                                    
    pip install pandas scikit-learn matplotlib seaborn

   3.Run the Notebook:

   Open income_prediction.ipynb in your preferred environment (Jupyter Notebook, VS Code, etc.) and execute all cells sequentially.
